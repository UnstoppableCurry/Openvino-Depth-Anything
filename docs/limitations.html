这份仓库证明不了什么

说明页如果写得像产品站，就会超出源码。下面把“仓库里没有的东西”写清楚，避免被读成评测或案例。

不是演示。 打开本站不会访问摄像头，也不会加载 Depth Anything 或 OpenVINO。深度图只可能出现在你本机编译运行之后的 OpenCV 窗口里。

本站与仓库都没有的内容

类别 仓库与本站的实际情况
精度 / 质量 没有任何定量评测、数据集名称或“准确率”陈述。
速度 draw_fps() 只在运行时往画面上画文字。README 和源码都没有写下测得的 FPS。
截图 README 的 ![Uploading 捕获.PNG…]() 是破损上传占位，不是结果图。本站不发明替代图。
权重 / ONNX / IR 仓库不含模型文件。README 提到的 depth_anything_vits14.onnx 需要自行取得并转换。
客户或生产 没有任何部署、客户、上线或产品化描述。
构建系统 没有 CMake、msbuild 工程、依赖版本或 main()。

从源码能直接看到的限制

  • Windows 痕迹： windows.h、SetConsoleOutputCP、以及 H:\vsworkspace\... 路径。
  • 入口不是 main： 可执行入口是 maindepth()，仓库没有给出谁调用它。
  • 路径与设备写死： 换机器必须改源码；README 的“set your model path / camera”与当前实现并不对应成配置文件。
  • 摄像头 0： 打不开设备时，循环仍会 video >> frame 并推理，源码没有检查 open 是否成功。
  • 编译失败可被吞掉： compileModel() 捕获异常后只打印，不中止构造。
  • 输出尺寸改写： Depth::inference 把 output_shape[0/1] 设为传入的 h/w，再按这个尺寸 memcpy。源码没有核对 OpenVINO 实际输出形状是否匹配。

和 Depth Anything 论文 / 官方实现的关系

仓库文件名、ONNX 文件名 depth_anything_vits14.onnx 以及 README 标题式用法表明目标是 Depth Anything 的 ViT-S/14 导出模型。仓库没有包含论文引用、官方权重来源、许可证说明，也没有声明自己实现了训练或完整算法。

本静态站还缺什么

合并之后，仓库 Settings → Pages 的 Source 需要设成 GitHub Actions，工作流才会往 https://unstoppablecurry.github.io/Openvino-Depth-Anything/ 发布 docs/。在此之前，上面这个地址可能仍是空的。

站点只使用相对路径引用页面和样式，以便挂在项目子路径 /Openvino-Depth-Anything/ 下。它不托管模型，也不执行 C++。
