仓库说明页

用 OpenVINO 跑 Depth Anything 的 C++ 源码

这是公开仓库 UnstoppableCurry/Openvino-Depth-Anything 的静态说明。内容只来自仓库里的 README.md 和四份 C++ 源文件，不补充未出现的指标或截图。

本站不是实时摄像头 / 深度估计演示。 浏览器里看不到深度图。要复现仓库行为，需要本机安装 OpenVINO、按 README 把 ONNX 转成 IR、自行设置模型路径和摄像头，再编译运行 C++ 程序。

  • 语言：C++
  • 推理：OpenVINO
  • 模型名：depth_anything_vits14.onnx
  • 转换形状：[1,3,518,518]
  • 可视化：COLORMAP_INFERNO

仓库里实际有什么

当前公开文件就是一份短运行说明，加上推理封装和深度后处理源码。没有构建脚本、没有模型权重、也没有可用的结果图。

  • README.md — 四步运行备忘：ONNX 转 IR、设模型路径、设摄像头、运行。
  • OpenvinoEngine.h / OpenvinoEngine.cpp — 读 IR、预处理、同步推理。
  • depth.h / depth.cpp — 方形填充缩放、推理、伪彩色、摄像头循环。

README 里的图不是结果图。 原文是破损的 Markdown 上传占位 ![Uploading 捕获.PNG…]()，链接为空。本站不把它当成截图，也不另做一张“效果图”充数。

能从源码确认的流程

  1. 01
    转模型 README 使用 OpenVINO Model Optimizer：mo --input_model="depth_anything_vits14.onnx" … --input_shape=[1,3,518,518]，输出名 depth，并 --compress_to_fp16。
  2. 02
    编译 IR OpenvinoEngine::compileModel() 读取 XML，用 PrePostProcessor 把输入从 BGR / NHWC / u8 转到 RGB / NCHW / f32，并按 255 做 scale，再 compile_model。
  3. 03
    摄像头循环 maindepth() 用 cv::VideoCapture 打开设备 0，每帧调用 Depth::inference(..., 518, 518)，窗口名是 frame 与 result。

以上逐步对应 README 与 depth.cpp / OpenvinoEngine.h。仓库没有公布帧率、精度或部署案例。
