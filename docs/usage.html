README 运行备忘

本机才能跑，页面上跑不了

README 只有四步，且没有安装、编译或依赖清单。下面原样列出这四步，再用源码补充它没写清、但已经写死的值。

在这个 GitHub Pages 站点上执行不了推理。需要本机的 OpenVINO（含 Model Optimizer mo）、ONNX 模型文件、转换后的 IR（源码读取 depth.xml）、可用的摄像头，以及能编译这些 C++ 文件的环境。

README 原文步骤

  1. 1
    onnx2ir 把 ONNX 转成 OpenVINO IR。
  2. 2
    set your model path 自行设置模型路径。README 没有给出推荐目录。
  3. 3
    set your camera 自行设置摄像头。README 没有写设备索引。
  4. 4
    run ~ 运行。README 没有写编译命令或可执行文件名。

README 里的转换命令

mo --input_model="depth_anything_vits14.onnx" --output_dir="./" --model_name="depth"    --compress_to_fp16 --input_shape=[1,3,518,518]

命令按 README.md 逐字复制，包括空格。仓库不包含 depth_anything_vits14.onnx，也不包含转换产物。

从这行能确定的只有：输入文件名是 depth_anything_vits14.onnx，输出模型名是 depth，压缩到 FP16，静态形状 [1,3,518,518]。Model Optimizer 成功时通常会写出 depth.xml 与配套的 bin；maindepth() 读取的正是 depth.xml。
